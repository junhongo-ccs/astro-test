Astroは「コンテンツ中心のサイト」に強いフレームワークです。

## 良かった点

- デフォルトではJavaScriptをほぼ出力しない(Zero JS by default)
- `.astro`コンポーネントの構文がシンプルで、HTMLに近い
- Markdown / MDXでブログのようなコンテンツを書きやすい

## 次にやること

- コンテンツコレクション(Content Collections)を使ってブログ記事を型安全に管理する
- レイアウトコンポーネントで共通のヘッダー・フッターをまとめる
- GitHub Pagesにデプロイしてみる
